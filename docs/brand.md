# Brand

torii is a product of **Inari Suite**. Its mark comes from the group's logo kit and follows the suite's grammar:
a black ring, a vermilion torii, and **one central symbol per tool**. For torii the symbol is the dark opening of
the gate with two fox eyes watching from inside it.

## Files

| File | Use |
|---|---|
| `assets/logo/torii-color.svg` | default mark, on light surfaces |
| `assets/logo/torii-dark.svg` | on dark surfaces |
| `assets/logo/torii-transparent.svg` | on any surface, no background tile |
| `assets/logo/torii-mono.svg` | one colour (stamps, print) |
| `assets/logo/torii-avatar-500.png` | profile picture |
| `assets/logo/favicon-32.png`, `apple-touch-icon-180.png`, `torii-512.png` | web icons |
| `assets/banner-light.svg`, `assets/banner-dark.svg` | README header (switches with the reader's theme) |
| `assets/social-preview.png` | GitHub social preview, 1280x640, uploaded in the repository settings |
| `assets/demo.svg` | animated replay of the real console session |

The banners set their text as outlines, so they look the same on every machine. They are produced from the kit by
`profiles/build_profiles.py` in the group's asset workspace; the demo is produced here by `scripts/build_demo.py`.

## Palette

| Name | Hex | Role |
|---|---|---|
| Ink | `#121A1A` | ring, dark backgrounds, body text on light |
| Paper | `#F5F3EA` | light backgrounds, ring on dark |
| Vermilion | `#C8432A` | the torii and the eyes: the only accent colour |

## Type

Geist for text, Geist Mono for code and metadata, Noto Sans JP for the kanji (鳥居, "torii"). All three are under the
SIL Open Font License.

## Voice

Plain, precise, and honest about limits. Concrete verbs: declare, approve, enforce. No "military-grade",
"unhackable" or "100%". The README says what torii does not stop before it asks you to trust it.
